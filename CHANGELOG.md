## [1.0.0] - 2026-11-20

- Initial exBASIC release, with native compiler packages for Windows, Linux,
  Intel macOS, and Apple Silicon macOS.
- Includes the Atari runtime libraries, assembler and linker tools, ATR image
  utility, target definitions, syntax files, manuals, and license notices.
- Adds functions, recursion, local variables, multiple return values, native
  integer-code generation, string concatenation, and cartridge output to the
  FastBasic-derived compiler.
